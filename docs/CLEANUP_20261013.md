## 授权和边界
用户批准保留底座、修正数据规则风险、清理覆盖式前端、降级固定样本诊断并 commit/push。本轮不实现新 Langfuse/ThoughtDAG 产品，不合并 main、不强推、不改历史、不删除私人源。

## 保留
Python只读服务/读取、line/byte/身份定位、稳定事件与轮次 occurrence、未知边界、公开结构测试、B2/C资产、有效地图和证据交互、单Session步骤图。

## 移除/替换及理由
- 已被后续覆盖的身份渲染器、四列身份墙、旧样本专用Inspector：错误展示不再作为fallback。
- 多次开机render/load：改为core → execution → data → agents后一次load；分文件保留有效逻辑。
- 特定身份的任务文案和历史404常量：无当前来源约束的内容不能当通用事实。现有角色词仅保留为明确待整理的预览线索。
- 固定历史DSH回执冒充当前审核：诊断不再读取其作为通过证据，显式NOT_ASSESSED。
- 多轮完成状态叠加：当前状态收敛为NOT_ACCEPTED；旧本机工作说明保留本地忽略归档，已有Git历史不改。

## 数据规则修正
镜像去重仅跳过同call ID的调用记录，保留输出。只有有明确sender的spawn建立父子；wait/send_input作为事件保留，不制造血缘。新增合成测试覆盖这些边界及重复Turn ID。
