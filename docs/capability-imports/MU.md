# mu Capability Import Contract

**Source role:** bounded conceptual reference  
**v0 status:** reference for a small Judgment abstraction only

## Candidate Concepts

- bounded Judgment abstraction;
- explicit Shadow mode;
- local Judgment Ledger concept;
- provider-independent judge boundary.

## Explicit Non-Imports

Do not import the pi runtime, Hive, a full context engine, a desktop shell,
the wholesale set of decision points, or a Jev dependency.

The first provider boundary is `DeepSeekJudgeProvider`. A provider response is
not runtime truth and never receives authority to alter Codex behavior in v0.
