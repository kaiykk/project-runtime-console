# Global Governance Bootstrap

This repository uses the reusable Global Multi-Agent Governance layer as a
governance adapter. It does not import the archived Project Evolution State
project, its research model, or its product artifacts.

## Authority

Human Principal authority is higher than Manager synthesis, Agent inference,
research compression, generated architecture, or reviewer interpretation.
`FRAME_OK`, `INTENT_PASS`, local `PASS`, and global review results are
advisory checkpoints, not Human ratification.

## Route

For model-shaping or Human-facing work:

```text
Human references
  -> bounded frame proposal
  -> independent frame check
  -> bounded execution
  -> local correctness audit
  -> intent-fidelity check
  -> global review
  -> Human Principal
```

Step 1 uses a deliberately light implementation of this route:

1. Human-frozen North Star and Shell Freeze;
2. independent H1/H2/H3 evidence comparison;
3. commitment gate;
4. local correctness audit;
5. Human-facing semantic smoke test;
6. final Global Review;
7. stop at `PRINCIPAL_REVIEW`.

## Knowledge Boundary

Keep knowledge state separate from engineering state. Implemented, tested,
running, or reviewed does not mean ratified. Unknown remains unknown, and
unsupported input paths must not be promoted into confirmed capability.

## Scope

This bootstrap governs the repository process. It is not a runtime feature and
does not authorize an Agent Control Plane, active intervention, autonomous
phase transition, or automatic judgment authority.
