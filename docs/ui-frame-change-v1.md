## TRIGGER

The current C0 presentation is a functional three-column runtime baseline,
but the Human-facing review identified that Agent topology, work progression,
branch relationships, progressive disclosure, and large-Run orientation are
not immediately legible. The Principal authorized a bounded UI convergence
round to test a graph-first Runtime Canvas against those observations.

## OLD_RULE

`docs/SHELL_FREEZE_V0.md` listed `ThoughtDAG canvas` as forbidden in v0, and
`docs/capability-imports/THOUGHTDAG.md` was `NOT_AUTHORIZED_FOR_V0`.

## NEW_RULE

ThoughtDAG-inspired graph-first Runtime Canvas is authorized for v0 as the
Presentation / Interaction Layer only. ThoughtDAG MIT code may be reused in a
bounded, attributed manner when the reuse record identifies source repository,
commit, path, license, local path, and modification.

The graph must remain a presentation of the existing Project/Run and Codex
Runtime Observer facts. It is not a new runtime model, ontology, or authority
surface.

## WHY

The amendment enables a falsifiable comparison of a graph-first presentation
against `UI_BASELINE_C0` while preserving runtime truth and the existing
observer boundary. It does not declare the graph-first frame successful; Pass
B and later browser evidence remain required.

## UNCHANGED_BOUNDARIES

- PRC North Star;
- Codex Runtime Model;
- Runtime Identity Contract;
- Step 1 `canonical_event_id` semantics;
- Judgment Sidecar boundary and shadow-only authority;
- Runtime Observer Independence requirement;
- read-only runtime lineage and provider facts;
- no editable runtime lineage, context-edge semantics, memory/model-context
  semantics, arbitrary user-created relationships, Control Plane, Task Board,
  Orchestrator, or active intervention;
- final Product UI approval remains Human-owned and the round stops at
  `PRINCIPAL_REVIEW`.

## PRINCIPAL_AUTHORITY

This amendment is authorized by the Human Principal instruction received for
`PRC-UI-CONVERGENCE-R1-20261006`. Reviewers may check alignment and evidence
discipline, but `FRAME_OK`, `INTENT_PASS`, Local `PASS`, and Global Review
remain advisory. The amendment does not authorize UI implementation before
Pass B returns `FRAME_OK`.
