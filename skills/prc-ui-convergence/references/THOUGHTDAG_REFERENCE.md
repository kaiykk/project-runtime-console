# ThoughtDAG Reference Boundary

Use the running ThoughtDAG product to observe canvas interaction grammar:
overview, branch geometry, semantic zoom, selection, focus, navigation,
detail disclosure, and large-graph orientation.

Do not import its conversation/context ontology, editable context edges,
memory/model context, Q/A model, or model invocation behavior. Any copied MIT
code requires source repository, commit, source path, license, local path, and
modification in the round's reuse record.
