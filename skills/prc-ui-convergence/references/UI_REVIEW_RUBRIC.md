# UI Review Rubric

Review evidence against observable tasks:

- root and direct-child discovery;
- branch readability;
- selected Agent trajectory isolation;
- overview -> Agent -> event -> overview continuity;
- semantic zoom and large-Run orientation;
- tool call/result discovery;
- status fidelity;
- no fabricated topology or trace leakage;
- no generic three-column dashboard drift.

Use `CONFIRMED`, `OBSERVED`, `HYPOTHESIS`, and `UNKNOWN` where claims differ
in evidence strength.
