# PRC Product Brief

The Human inspects a real Codex Run during and after execution:

```text
Project -> Run -> observed Agent topology -> Agent trajectory -> runtime event -> optional shadow judgment
```

The graph-first canvas is a presentation/interaction layer. It must preserve
native identity, parent edges, observed status, trace ownership, and explicit
unknowns. It must not allow editing runtime lineage or import ThoughtDAG's
conversation/context ontology. Product approval remains Human-owned.
